# TaskFlow API Documentation

## 1. Overview

The TaskFlow API is built using FastAPI and follows RESTful conventions. Interactive documentation is automatically generated by FastAPI:
- **Swagger UI:** `http://localhost:8000/docs`
- **ReDoc:** `http://localhost:8000/redoc`
- **OpenAPI Schema:** `http://localhost:8000/openapi.json`

Base API prefix: `/api/v1`

---

## 2. Endpoints

### 2.1 Health Check

Verifies backend service availability, environment state, and release version.

- **URL:** `/health` (also accessible at `/api/v1/health`)
- **Method:** `GET`
- **Authentication:** None
- **Headers:** None required

#### Success Response
- **Code:** `200 OK`
- **Content-Type:** `application/json`

```json
{
  "status": "healthy",
  "app_name": "TaskFlow API",
  "version": "0.1.0",
  "environment": "development",
  "timestamp": "2026-10-22T05:30:00Z"
}
```

#### Response Attributes
| Field | Type | Description |
|---|---|---|
| `status` | string | Health indicator (e.g., `"healthy"`) |
| `app_name` | string | Name of the service |
| `version` | string | Current deployed semver |
| `environment` | string | Deployment environment (`development`, `staging`, `production`) |
| `timestamp` | string (ISO 8601) | Server UTC timestamp of the check |

## 3. Planned Endpoints (Roadmap)

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/v1/auth/register` | Register a new user |
| `POST` | `/api/v1/auth/token` | Obtain JWT bearer access token |
| `GET` | `/api/v1/tasks` | List tasks for authenticated user |
| `POST` | `/api/v1/tasks` | Create a new task |
| `GET` | `/api/v1/tasks/{id}` | Retrieve specific task details |
| `PUT` | `/api/v1/tasks/{id}` | Update existing task |
| `DELETE` | `/api/v1/tasks/{id}` | Delete a task |

## 4. Status Codes

| Code | Status | Meaning |
|---|---|---|
| `200` | OK | Request succeeded |
| `201` | Created | Resource successfully created |
| `400` | Bad Request | Validation error or malformed payload |
| `401` | Unauthorized | Missing or invalid authentication token |
| `404` | Not Found | Resource not found |
| `422` | Unprocessable Entity | Pydantic validation failure |
| `500` | Internal Server Error | Unhandled server exception |
